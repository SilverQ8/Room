## 🎮 조작 가이드 (Controls)

| 조작 | 기능 |
| :--- | :--- |
| **마우스 우클릭 + 드래그** | **3D 시점 궤도 회전** (360° 자유 회전) |
| **마우스 휠 스크롤** | **줌 인 / 줌 아웃** (확대 / 축소) |
| **마우스 휠 클릭 + 드래그** | **시점 패닝** (Pan - 시점 위치 평행 이동) |
| **가구 마우스 좌클릭** | **가구 선택** (선택 시 노란색 하이라이트 박스 표시) |
| **선택 가구 좌클릭 + 드래그** | **3D 바닥 평면 위 가구 실시간 이동** (10cm 단위 자동 스냅) |
| **키보드 `R` 키** | **선택 가구 Y축 90도 회전** |
| **키보드 `Delete` 또는 `Backspace`** | **선택 가구 삭제** |

## ✨ 데모에 포함된 주요 기능

1. **3D 가구 6종 프리셋 모델링**:
   - 🛏️ **침대**: 원목 프레임, 매트리스, 헤드보드, 베개 2개 포함
   - 🖥️ **책상**: 상판, 4개 다리, 듀얼 스탠드 모니터 소품 포함
   - 🪑 **의자**: 좌판, 등받이, 4개 다리
   - 🚪 **옷장**: 양문형 옷장 바디 및 은색 손잡이
   - 🛋️ **소파**: 등받이, 쿠션 시트, 양측 팔걸이
   - 📺 **TV 및 거실장**: 거실 테이블, 받침대, 대화면 평면 TV

2. **3D 충돌 감지 (Collision Detection)**:
   - 가구끼리 공간에서 겹치면 자동으로 **붉은색(Red) 경고 하이라이트**로 전환됩니다.

3. **실시간 속성 편집 패널 (우측)**:
   - 선택된 가구의 **위치(X, Z), Y축 회전각, 치수(가로 W, 세로 D, 높이 H), 색상**을 슬라이더와 색상 선택기로 즉시 변경할 수 있습니다.

4. **상단 툴바 & 뷰 프리셋**:
   - `3D 뷰 리셋`: 기본 3D 아이소메트릭 각도로 카메라 복귀
   - `탑뷰 (2D 평면도)`: 위에서 수직으로 내려다보는 2D 도면 시점으로 원클릭 전환
   - `선택 회전`, `선택 삭제` 바로가기 버튼

## 📁 프로젝트 구조
- `src/main/java/com/roomplanner/`
  - `Main.java` / `App.java`: 애플리케이션 진입점 및 메인 윈도우 레이아웃
  - `model/FurnitureItem.java`: 3D 가구 모델링 및 바운딩 박스/충돌 연산
  - `view/RoomViewport3D.java`: 3D SubScene, 궤도 카메라, 조명, 바닥 그리드 및 마우스 피킹
  - `view/SidebarCatalog.java`: 좌측 가구 카탈로그 UI
  - `view/PropertyPanel.java`: 우측 가구 치수 및 속성 편집 UI
- `javafx-sdk-21.0.3/`: JavaFX 3D 런타임 라이브러리
- `compile.bat` / `run.bat`: 원클릭 컴파일 및 실행 스크립트
- `ROOM_PLANNER_SPEC.md`: 전체 3D 룸 플래너 설계 사양서
